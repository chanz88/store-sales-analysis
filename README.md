# Superstore Sales and Profit Analysis

## Overview
This project analyzes the Superstore dataset to identify patterns in sales, profit, products, regions, customer segments, and discounts

## Dataset used
The dataset used in this project consists of 9994 sales transactions across 21 columns, detailing orders, customers, products, sales, discounts, and profit

## Objective
- Analyze overall sales and profit performance
- Identify sales and profit trends over time
- Analyze sales and profit by product category
- Identify top performing products
- Compare performance across regions
- Analyze customer segments
- Explore the relationship between discount and profit

## Conclusion
This analysis highlights what drives sales and profitability in the Superstore dataset
